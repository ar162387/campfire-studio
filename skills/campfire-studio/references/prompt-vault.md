# Nine prompts for the existing engine

Give the agent `AGENTS.md`, the current exported episode and the relevant references. In every prompt: return valid version-1 Campfire episode JSON, preserve IDs/media/cast unless changing them is requested, use only registered controls, put delivery cues in `delivery`, and do not claim speech has been generated. Use original dialogue. Never turn a competitor transcript into a close paraphrase.

## 1. Premises

Generate ten original premises for this audience: [audience]. Each starts with Claude plus a specific problem, has an early inversion, one escalating visual receipt, one concrete recurring prop and a short final button. Use only truthful experience supplied here or mark the premise fictional. Rank by recognisable tension, not predicted views. Give five hook shapes across the set.

## 2. Full episode

Using this premise [premise] and this current project JSON, write 20–29 short lines for roughly 50–60 seconds. Hook on frame zero, twist before ten seconds, one sincere beat around two-thirds, plant/payoff, short final mascot line and 1.2-second pose hold. Set story roles, restrained actions, speaker close-ups, clause caption cards and a useful working-screen event. Timing remains estimated until aligned speech. Keep the story's sales ask in the post caption.

## 3. Joke pass

Review this script without changing its underlying incident. Strengthen three escalation rungs with distinct specific receipts. Remove repeated explanations and generic AI jokes. Make the Host's flawed logic understandable and Claude's corrections brief. Keep one sincere beat and preserve the planted callback. Return changed beats and the complete valid JSON.

## 4. Timing repair

Inspect these measured word timings and the current script. Find rushed lines, unnecessary gaps, caption changes inside a phrase and camera changes that do not earn a reaction. Keep speech continuous across camera cuts. Do not stretch or duplicate the audio. Retain successful takes; flag actual pickup dialogue separately. Return retimed episode and a timing provenance note.

## 5. Performance direction

Direct the current episode using seven base moods, the registered actions, body states and blocking in characters.md. Claude is usually neutral/smug; let the Host carry the larger reaction. Use an action when it adds information, not on every line. Reserve powered-down, blush or dizziness for a story reason. Props stay attached until explicitly released or passed to a recipient on the next beat. Check the camera after changing body position.

## 6. Continuity

Read this series ledger and propose three future premises that pay off an earlier object or promise. Do not claim an unrecorded event happened. Keep cast IDs and character looks consistent. Give Claude a small private want. For the chosen episode set continuityPlant or continuityPayoff, then validate against the ledger before recording it.

## 7. First three seconds

Offer five original openings for this incident: [incident]. Compare speaker face versus listener reaction and an interrupted-screen variant. The first caption must be the first spoken words. Name the tension and the first reply that reframes it. No intro card, greeting, unsupported number or in-video sales pitch. Keep the strongest opening and preserve the rest of the story's promise.

## 8. Voices

Read voices.md. Discover available models/voices before locking a cast. Prepare an ordered, explicit-model dialogue request with emotive delivery tags and pronunciation aliases; captions contain the written dialogue only. Generate only with existing user authorization and available credentials. Save provider response and audio before validating alignment. If timing fails, align the same take instead of paying to regenerate it. Export a portable episode with measured timing and report what was actually tested.

## 9. Caption, cover and experiment

Write a post caption with one engagement question for this episode, natural audience search terms, a small relevant hashtag set and a pinned question that does not duplicate the caption. Produce an in-world cover frame with series/episode badge, one warm accent word and a verbatim line. Prepare matched chunk/karaoke variants, holding audio/story/performance constant. Record reach, watch time, completion, shares and saves after equal windows. Do not declare a winning format without results.
